# Shared video files

Finished web versions of the companion videos (MP4, captions as WebVTT, a
thumbnail), shared through this branch (`video-files`) so the Mac and Windows
sessions and the site can fetch them. Not for `main`: don't merge this branch.

- `mac/`: Installing on a Mac, Your first launch, What each setting means
  (made on the Mac, from v0.1.0-alpha.4).
- `windows/`: the Windows videos, added by the Windows session.

Names match the scripts in docs/videos/ on `videos-mac-install-and-first-launch`
and `videos-windows`. Narration audio for the Windows videos is on
`videos-windows-narration`.
